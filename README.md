Microfinance Bank Sales Analysis Dashboard Report
This report summarizes the Power BI dashboard for the Microfinance Bank Sales Analysis.


Executive Summary
The dashboard provides an overview of loan disbursement, repayment, default, outstanding balance, branch performance, loan type performance and monthly trends. It supports management in monitoring lending performance and making strategic decisions.
Key KPIs
•	Total Loan Disbursed: ₦165.06M
•	Total Loan Repaid: ₦76.09M
•	Outstanding Balance: ₦88.97M
•	Average Interest Rate: 10.22%
•	Displayed Default Rate: 400% (this KPI should be validated because it appears inconsistent with normal default-rate calculations).
Insights
•	Branch L1 recorded the highest loan disbursement (~₦34M).
•	Agricultural loans generated the highest interest income.
•	Monthly loan disbursement peaked at approximately ₦17.2M and the lowest month recorded about ₦11.0M, indicating a ₦6.2M variation.
•	Lokoja recorded the highest repayment amount among cities shown.
•	Outstanding loans remain significant, suggesting stronger recovery efforts are required.
Recommendations
•	Strengthen credit assessment in high-default branches.
•	Expand agricultural lending while maintaining risk controls.
•	Improve loan recovery processes to reduce outstanding balances.
•	Review pricing and interest strategy to improve affordability without increasing risk.
•	Monitor monthly lending trends for capacity planning.
Conclusion
Overall, the dashboard provides management with a clear view of lending performance and highlights opportunities to improve repayment, reduce defaults, and optimize loan portfolio growth.
